# คลังช่าง · mockup เบิก/เติมสต็อกแนวช็อปปิ้งออนไลน์

mockup สำหรับนำเสนอลูกค้า กดใช้งานได้ครบลูป ไม่มีเซิร์ฟเวอร์ ไม่ต้องติดตั้งอะไร

## วิธีเปิด

ดับเบิลคลิก `index.html` (Chrome / Edge) — ใช้ได้ทั้งมือถือ (390px) และคอม

- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่เปิด (localStorage) ปิดแล้วเปิดใหม่ข้อมูลยังอยู่
- **รีเซ็ตก่อนเดโมทุกครั้ง:** ปุ่ม "เดโม" (ใต้หัวเว็บ) → "รีเซ็ตข้อมูลตัวอย่าง"
- ฟอนต์โหลดจาก Google Fonts ถ้าไม่มีอินเทอร์เน็ตจะใช้ฟอนต์ของเครื่องแทน ส่วนอื่นทำงานออฟไลน์ได้

ปุ่ม "เดโม" ยังมี: สวิตช์ "ใบเบิกต้องให้หัวหน้าอนุมัติ" · "จำลองจ่ายของไม่สำเร็จ" · ล็อกคลังนับสต็อกรายคลัง
สลับผู้ใช้ (วิศวกร / Store / หัวหน้า) ที่ช่องเลือกชื่อใต้หัวเว็บ

## สคริปต์เดโม 10 ฉาก

ทุกฉากเริ่มจากกด "เดโม" → "รีเซ็ตข้อมูลตัวอย่าง" · ผู้ใช้ 3 คนสลับที่ช่องเลือกชื่อใต้หัวเว็บ

**ฉาก 1 · เบิกแล้วของขาด → เติมสต็อก → ได้ของครบ** (ลูปหลัก)
1. ผู้ใช้ *สมชาย (วิศวกร)* → หน้าร้าน ใส่ตะกร้า "สายไฟ THW 1.5 sq.mm สีดำ" และ "กล่องพักสาย 4x4 นิ้ว"
2. ตะกร้า: ขอเบิก 80 m และ 85 ใบ → เลือก *คลังหลัก* (เห็น พอ / ขาด 31 ใบ และกล่องเหลือง) → งาน *ไซต์งาน A เฟส 2* → **เบิกเลย**
3. การ์ดผล "จ่ายบางส่วน": ตัดจากม้วน R-000160 เหลือ 20 m · กล่องจ่าย 54 จาก 85 · รายการต้องซื้อ PR-690002
4. สลับเป็น *ก้องภพ (Store)* → ระฆัง → รายการต้องซื้อใหม่ PR-690002 → แตะรายการกล่องพักสาย → **ยืนยันรับของเข้า** (ค่าเริ่มต้นคือ 31 ใบที่ค้างรับ)
5. สลับกลับ *สมชาย* → ระฆัง "ของที่รอ…เข้าแล้ว" → **จ่ายของ** → สถานะ "จ่ายครบ"

**ฉาก 2 · สายไฟต้องเป็นเส้นเดียว**
สมชาย ใส่ "สายไฟ THW 1.5 sq.mm สีดำ" 150 m → คลังหลัก → เปิด "ม้วนที่จะตัด" ติ๊ก *ต้องเป็นเส้นเดียว* → กล่องแดง + ปุ่มเบิกจาง → เอาติ๊กออก หรือสลับคลัง

**ฉาก 3 · ส่งเบิกรอหัวหน้าอนุมัติ**
เดโม → เปิด "ใบเบิกต้องให้หัวหน้าอนุมัติ" → สมชายเบิกเบรกเกอร์ 5 ตัว → ปุ่มเป็น **ส่งเบิก** → การ์ด "รออนุมัติ" → สลับเป็น *อรุณ (หัวหน้า)* → เมนู อนุมัติ → **อนุมัติ** → สมชายได้แจ้งเตือน

**ฉาก 4 · สร้างสินค้าใหม่ + Store ยืนยันยอด**
สมชาย ค้น "น็อต" → "สร้างสินค้าใหม่" → หมวด *วัสดุสิ้นเปลือง* → หน่วย *ตัว* → เปิด "มีของนี้อยู่ในคลังแล้ว" 100 ตัว → สร้าง → เบิก 10 ตัว (การ์ด "รอของเข้า · รอ Store ยืนยันยอด") → สลับเป็น Store → แบนเนอร์หน้าแรก "มียอดรอคุณยืนยัน" (หรือเมนู อนุมัติ) → **ยืนยันยอด** → สมชาย **จ่ายของ**

**ฉาก 5 · คืนของ** (ทีละขั้น)
สมชาย → เมนู คืนของ → แตะใบเบิก REQ-690006 → **คืนทั้งหมด** (หรือใส่จำนวนทีละรายการ) → ขั้น 3 คลังหลัก ชั้น ทั่วไป → **บันทึกคืนของ** → การ์ด "บันทึกคืนของแล้ว" + ใบหายจากรายการ ยอดในหน้าร้านเพิ่มกลับ

**ฉาก 6 · คืนของเสียหาย → ชั้นรอตรวจ → ตัดสิน**
สมชาย → คืนของ → REQ-690006 → เบรกเกอร์ ใส่ 2 → กด *เสียหาย* → **บันทึกคืนของ** (ของไปอยู่ชั้นรอตรวจ ยังเบิกไม่ได้) → สลับเป็น Store → คืนของ → ปุ่ม *ชั้นรอตรวจ* → เบรกเกอร์ รอตรวจ 2 ตัว → **คืนเข้าชั้น** → เลือก A-01 → **ยืนยันคืนเข้าชั้น** (หรือ **ตัดทิ้ง** ใส่เหตุผล) · วิศวกรเปิดหน้านี้ไม่ได้

**ฉาก 7 · แก้สินค้า / เลิกใช้**
สลับเป็น Store → ปุ่ม *สินค้า* (แถบผู้ใช้) → แถวเบรกเกอร์ **แก้** → แก้ได้เฉพาะชื่อ ยี่ห้อ รุ่น บาร์โค้ด หมายเหตุ (หมวด หน่วย ต้องอนุมัติ หน่วยตอนสั่งซื้อ เตือนสั่งซื้อ ขึ้นป้าย "หัวหน้าเท่านั้น") → ใส่หมายเหตุ → **บันทึก** → สลับเป็นหัวหน้า → สินค้า → "สายไฟ VAF 2x1.5 sq.mm" (ไม่มีของเลย) **แก้** → **เลิกใช้สินค้า** → ยืนยัน → สินค้าหายจากตัวเลือกตอนเบิก ประวัติยังอยู่ · ตัวที่ยังมีของ หัวหน้าเลิกใช้ไม่ได้

**ฉาก 8 · ปิดงาน**
(ทำฉาก 1 ข้อ 1-3 ก่อน ยังไม่ต้องรับของ) → Store → ปุ่ม *งาน* → J-25-010 → **ปิดงาน** → ข้อความ "ยังมีใบเบิกที่ไม่ปิด" → ใบเบิก REQ-690007 → **ปิดใบเบิก** (ช่อง "ยกเลิกรายการต้องซื้อที่ยังไม่ได้ของ" ติ๊กไว้ให้ ไม่ต้องการก็เอาออก) → กลับ งาน → **ปิดงาน** → กล่องยืนยันแสดง "ยังมีของที่เบิกไปแต่ยังไม่คืน" ทีละรายการ → **ปิดงาน** · งานปิดแล้วเบิกเพิ่มไม่ได้ แต่คืนของได้

**ฉาก 9 · รับของเกิน และของมาส่งโดยไม่มีใบขอซื้อ**
(ทำฉาก 1 ข้อ 1-3 ก่อน) Store → รับของ → แตะกล่องพักสาย → พิมพ์จำนวนที่รับ *40* (ค้างรับ 31) → ขึ้น "รับเกินที่สั่ง 9 ใบ ใส่เหตุผล" → กรอก "เหตุผลที่รับเกิน" → **ยืนยันรับของเข้า** → ต่อ: **ของมาส่งโดยไม่มีใบขอซื้อ** → ค้นหา "เทปพัน" → เลือก → ใส่ 10 → **ยืนยันรับของเข้า** (ระบบสร้างรายการ "รับไม่มีใบ" ให้เอง)

**ฉาก 10 · นำเข้ายอดยกมาจาก CSV (หัวหน้า)**
สลับเป็นหัวหน้า → ปุ่ม *ยอดยกมา* (แถบผู้ใช้) → **ดาวน์โหลดไฟล์ตัวอย่าง** → เลือกไฟล์นั้น (มีแถวผิด 1 แถว รหัส P-9999 แสดงสีแดง) → **ตัดแถวที่ผิด (1)** → **นำเข้ายอดยกมา** → ยอดเข้าคลังทันที ดูประวัติได้ที่ปุ่ม *ประวัติ* · Store เปิดหน้านี้ไม่ได้ · ปุ่ม "ล็อกยอดยกมา" กันนำเข้าซ้ำ

ฉากเสริม: เดโม → ล็อก "คลังหลัก" ขณะกรอกตะกร้า (คลังถูกล้าง + ข้อความแจ้ง งานที่เลือกยังอยู่) · "จำลองจ่ายของไม่สำเร็จ" (การ์ด "จ่ายไม่สำเร็จ" → ไปหน้าหยิบ) · หน้ารับของ แท็บ "ใกล้หมด" (เบรกเกอร์ต่ำกว่าเกณฑ์)

## รูปสินค้า

ตอนนี้ใช้ภาพประกอบ SVG ใน `img/products/` (วาดเอง ไม่มีลิขสิทธิ์ภายนอก)
